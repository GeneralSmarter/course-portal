Fourier sine-series recap

The lecture revisited the distinction between odd and even functions:

• An odd function satisfies:

\[

f(-x)=-f(x)

\]

• An even function satisfies:

\[

f(-x)=f(x)

\]

• Sine functions are odd.

• Cosine functions are even.

• A full Fourier series contains both sine and cosine terms. The lecture focused on the sine series for the following weeks.

For a Fourier sine series on \(0 \leq x \leq L\):

\[

f(x)=\sum_{n=1}^{\infty}b_n\sin\left(\frac{n\pi x}{L}\right)

\]

with coefficients:

\[

b_n=\frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right)\,dx

\]

The lecturer applied this to the constant function \(f(x)=1\), using \(L=1\):

\[

b_n=2\int_0^1 \sin(n\pi x)\,dx

\]

Integration gives:

\[

b_n=\frac{2}{n\pi}\left(1-\cos(n\pi)\right)

\]

Since:

\[

\cos(n\pi)=(-1)^n

\]

the coefficient depends on whether \(n\) is odd or even:

• If \(n\) is odd:

\[

\cos(n\pi)=-1

\]

and:

\[

b_n=\frac{4}{n\pi}

\]

• If \(n\) is even:

\[

\cos(n\pi)=1

\]

and:

\[

b_n=0

\]

Therefore, the constant function has the sine-series representation:

\[

\left[

\sin(\pi x)

+\frac{1}{3}\sin(3\pi x)

+\frac{1}{5}\sin(5\pi x)

+\cdots

\right]

\]

\[

\sum_{\substack{n=1\\n\ \mathrm{odd}}}^{\infty}

\frac{1}{n}

\sin\left(\frac{n\pi x}{L}\right)
