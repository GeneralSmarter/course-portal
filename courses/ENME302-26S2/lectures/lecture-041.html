Transition from 1D to 2D finite elements

The two-dimensional finite-element method follows the same overall principles as the one-dimensional method:

1. Divide the continuous domain into finite elements.

2. Define an interpolation approximation within each element.

3. Construct shape functions.

4. Form element equations.

5. Assemble the element equations into a global system.

6. Apply boundary conditions and solve for the unknown nodal values.

The main additional difficulties in 2D are:

• More complicated geometry.

• More involved calculus.

• Additional coordinate directions.

• Increased bookkeeping.

• More complex assembly and solution procedures.

Elements may be triangular or quadrilateral. The lecture focused on a three-node linear triangular element.

The dependent variable is evaluated at the element nodes. For a triangular element with nodes \(1\), \(2\), and \(3\), the nodal values are \(U_1\), \(U_2\), and \(U_3\), located at

\[

(x_1,y_1),\qquad (x_2,y_2),\qquad (x_3,y_3).

\]

Linear triangular interpolation

A linear approximation over a triangular element has the form

\[

\tilde{u}(x,y)=Ax+By+C.

\]

The constants \(A\), \(B\), and \(C\) are determined by requiring the approximation to equal the known nodal values at the three nodes:

\[

Ax_1+By_1+C=U_1,

\]

\[

Ax_2+By_2+C=U_2,

\]

\[

Ax_3+By_3+C=U_3.

\]

These equations can be written in matrix form:

\[

\begin{bmatrix}

1 & x_1 & y_1\\

1 & x_2 & y_2\\

1 & x_3 & y_3

\end{bmatrix}

\begin{bmatrix}

C\\A\\B

\end{bmatrix}

=

\begin{bmatrix}

U_1\\U_2\\U_3

\end{bmatrix}.

\]

Solving this system and regrouping the coefficients of the nodal values gives

\[

\tilde{u}(x,y)

=

N_1(x,y)U_1

+

N_2(x,y)U_2

+

N_3(x,y)U_3.

\]

The shape functions are linear in x and y. They satisfy the Kronecker-delta property:

\[

N_i(x_j,y_j)=

\begin{cases}

1,&i=j,\\

0,&i\ne j.

\end{cases}

\]

They also satisfy the partition-of-unity property:

\[

N_1+N_2+N_3=1.

\]

For a triangular element with area \(A_e\), the standard shape functions are

\[

N_1(x,y)

=

\frac{1}{2A_e}

\left[

(x_2y_3-x_3y_2)

+

(y_2-y_3)x

+

(x_3-x_2)y

\right],

\]

\[

N_2(x,y)

=

\frac{1}{2A_e}

\left[

(x_3y_1-x_1y_3)

+

(y_3-y_1)x

+

(x_1-x_3)y

\right],

\]

\[

N_3(x,y)

=

\frac{1}{2A_e}

\left[

(x_1y_2-x_2y_1)

+

(y_1-y_2)x

+

(x_2-x_1)y

\right].

\]

The element area is

\[

A_e

=

\frac{1}{2}

\left[

x_1(y_2-y_3)

+

x_2(y_3-y_1)

+

x_3(y_1-y_2)

\right],

\]

with the absolute value used if only the positive geometric area is required.

Because the shape functions are linear, their derivatives are constant throughout the element. This makes the gradients easy to take outside certain element integrals.

Galerkin weighted-residual method

The lecture introduced the two-dimensional weighted-residual method. For a residual \(R(x,y)\), the weighted residual statement is

\[

\int_{\Omega} w_i(x,y)R(x,y)\,d\Omega=0,

\]

for each weighting function \(w_i\).

In the Galerkin method, the weighting functions are chosen to be the same as the shape functions:

\[

w_i=N_i.

\]

The two-dimensional domain integral is a double integral over the element or complete computational domain.

Weak form and Green’s theorem

The second derivatives in the strong form are undesirable for the finite-element approximation. Green’s theorem, the two-dimensional analogue of integration by parts, is used to reduce the derivative order.

The resulting weak form has the structure

\[

\int_{\Omega}

\left(

\frac{\partial \tilde{u}}{\partial x}

\frac{\partial N_i}{\partial x}

+

\frac{\partial \tilde{u}}{\partial y}

\frac{\partial N_i}{\partial y}

+

\rho N_i

\right)

\,d\Omega

=0,

\]

subject to the sign convention used for the governing Poisson equation.

The weak form is the form from which the element equations are constructed.
