Overview

This lecture reviewed the finite-element workflow for solving two-dimensional pin-jointed bar or truss structures and introduced the computational approach used in the laboratory.

Main topics:

Key concepts

• Global displacement vector: The solved vector of structural degrees of freedom, denoted in the transcript using lower-case q or possibly Q depending on context. It contains the allowable nodal translations in the global coordinate system.

• Global applied-force vector: The corresponding vector of externally applied nodal forces, apparently denoted by upper-case Q in the lecture notation. The exact capitalisation should be checked against the course notes.

• Element displacement vector: The displacement degrees of freedom associated with one element, denoted d in the transcript.

• Element force vector: The internal force components associated with an element, obtained after post-processing.

• Assembly matrix: A matrix containing only zeros and ones. It maps element degrees of freedom to global degrees of freedom and is used both to assemble the global stiffness matrix and to extract element-specific quantities from global vectors.

• Local coordinates: Coordinates attached to an individual element. For a two-dimensional bar, the local x-axis is aligned with the element.

• Global coordinates: The common structural coordinate system, normally global x and global y.

• Transformation matrix: Incorporates the element orientation angle, denoted α, when converting local element quantities into global coordinates.

• Local element stiffness matrix: Depends on the element’s material and geometric properties, principally Young’s modulus E, cross-sectional area A, and length L.

• Transformed element stiffness matrix: Includes the element orientation but not its structural connectivity.

• Assembled element contribution: Includes the element’s orientation and its connectivity to the global structure.

• Global stiffness matrix: The sum of all assembled element contributions. It represents the complete structure.

• Post-processing: Analysis performed after solving the global stiffness equation, including calculation of reactions, element forces, strains, and deformed geometry.

• Boundary conditions: Fixed or supported degrees of freedom are assigned zero displacement and do not receive independent global displacement variables.

• Physical interpretation: Signs and magnitudes of calculated forces and displacements must be checked against free-body diagrams and support conditions.

• Consistency of element orientation: An element may be numbered in either direction, but the chosen direction and associated local coordinate system must be used consistently. Intermediate matrices may change, while the final physical result should remain unchanged.

• Bar-element degrees of freedom: A two-dimensional bar element has four global-coordinate displacement components, two at each node. Frame elements will later have six element degrees of freedom according to the lecture.

• Matrix structure: Horizontal or vertical elements may produce uncoupled equations in the chosen coordinates, whereas inclined elements generally produce off-diagonal terms and coupled equations.

• Computational advantage: Adding elements makes manual methods rapidly more difficult, while the finite-element workflow changes comparatively little.

3. Assembly matrix

The assembly matrix contains zeros and ones. A one indicates that a particular element degree of freedom corresponds to a particular global degree of freedom. A zero indicates no correspondence.

For a bar element:

• The number of columns equals the number of element degrees of freedom, normally four.

• The number of rows equals the number of global structural degrees of freedom.

• Each column identifies where one element degree of freedom belongs in the global vector.

The assembly matrix does not scale quantities or create new numerical values. It places or extracts existing values in the appropriate locations.

The lecturer highlighted two uses:

1. Assembly:

• It places each element stiffness contribution into the correct locations of the global stiffness matrix.

2. Extraction:

• Once the global displacement vector has been solved, it extracts the components relevant to a particular element.

This becomes increasingly valuable for larger structures. A global displacement vector may contain dozens or hundreds of values, while any individual bar element only requires four relevant displacement components.

4. Force equilibrium

At each node, the sum of internal element-force contributions must balance the applied external load.

If the external nodal load is non-zero, the corresponding internal-force contributions must sum to that load. If no external load is applied at a node, the corresponding sum should be zero.

Support reactions are obtained from the element force vectors connected to the support. If multiple elements meet at one support, the total reaction must include contributions from every connected element.

The lecturer repeatedly connected the algebraic force vector to the free-body diagram. A vector of numbers has no useful physical interpretation until its entries are associated with directions, nodes, and element axes.

5. Local and global coordinates
