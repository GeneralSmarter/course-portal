Key concepts

• A second-order differential governing equation requires two integrations to obtain its analytical solution.

• Boundary conditions determine the constants of integration.

• For a uniform rod with constant properties and a constant applied force, the displacement varies linearly with position.

• The analytical solution provides a reference against which the finite-difference code can be validated.

• A second-order finite-difference approximation reproduces a linear function exactly, subject to numerical precision.

• Interior finite-difference nodes usually share the same coefficient pattern; boundary nodes require separate treatment because their available neighbouring nodes differ.

• Finite-difference accuracy is described by the order of the leading truncation error:

• second-order accurate: error proportional to \(\Delta x^2\)

• third-order accurate: error proportional to \(\Delta x^3\)

• fourth-order accurate: error proportional to \(\Delta x^4\)

• Higher-order schemes generally use more grid points in their stencil.

• On a log-log plot of error against grid spacing, the slope gives the observed order of accuracy.

• The two-dimensional Laplace equation can be discretised using second-order central differences in both coordinate directions.

• Dirichlet boundary conditions prescribe the temperature directly on the boundary.

Why the numerical and analytical solutions coincide

The analytical displacement field is linear in \(x\). The central finite-difference approximation used for the governing second derivative is second-order accurate and exactly reproduces the second derivative of a linear function, which is zero.

Consequently, the discrete equations recover the linear analytical solution at the grid points. Increasing or decreasing the number of grid points does not introduce an observable discretisation error for this particular linear test problem, although floating-point round-off may still exist.

This is a useful verification case because it tests whether the code correctly represents:

• The governing equation.

• The boundary conditions.

• The coefficient matrix.

• The solution of the linear system.
