Key concepts

• Computational domain: The spatial and temporal grid used to approximate the continuous governing equation.

• Nodal point: A discrete point in space and time at which the dependent variable is evaluated.

• Central differencing: A finite-difference approximation using values on both sides of the point being approximated.

• Two-step explicit scheme: The new time level depends on the two preceding time levels.

• Ghost point: An additional fictitious point introduced outside the physical domain or before the initial time to apply a finite-difference formula.

• Initial displacement condition: Specifies the string displacement at \(t=0\).

• Initial velocity condition: Specifies \(\partial u/\partial t\) at \(t=0\).

• Dirichlet boundary condition: Specifies the value of the dependent variable, such as zero displacement.

• Neumann boundary condition: Specifies a derivative, such as zero slope.

• Stability: A numerical solution should not develop unbounded, nonphysical oscillations or amplitudes.

• Courant-type parameter:

\[

\lambda=\frac{c\Delta t}{\Delta x}

\]

• Stability requirement for the explicit wave-equation scheme:

\[

\lambda<1

\]

as stated in the lecture.

• Mesh refinement: Reducing \(\Delta x\) requires a corresponding reduction in \(\Delta t\) to maintain stability.

• Linear PDE: The dependent variable and its derivatives occur only to the first power and are not multiplied together.

• Homogeneous PDE: There are no forcing terms independent of the dependent variable.
