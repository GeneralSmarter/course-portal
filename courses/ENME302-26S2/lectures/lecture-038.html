Finite-element discretisation

The lecture began by revisiting what a finite-element solver does. A continuous domain is tessellated into smaller elements, with each element described using nodes. The unknown field may be a displacement field, temperature field, or another dependent variable.

The finite-element procedure approximates the field within each element using interpolation or shape functions. The nodal values become the unknowns in a system of algebraic equations.

For four linear elements:

• There are four intervals or elements.

• Five nodes are required.

• Each linear element has two local degrees of freedom.

• Neighbouring elements share the degree of freedom at their common interface.

• The assembled system therefore has five global degrees of freedom.

For two quadratic elements:

• Each quadratic element has three local degrees of freedom.

• The midpoint of each element is an additional node.

• With shared interface nodes, the two-element system also has five global degrees of freedom.

• A quadratic function requires three points to be uniquely identified, whereas a linear function requires two points.

The lecture compared four linear elements and two quadratic elements over the same interval. Both discretisations resulted in five global unknowns, but the quadratic elements provided a more accurate representation of a quadratic field.
