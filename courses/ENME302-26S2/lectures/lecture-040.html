Key concepts

• Finite-element assembly:

• Each element contributes only to the global rows and columns associated with its local nodes.

• Element 1 uses degrees of freedom \(T_1,T_2\).

• Element 2 uses \(T_2,T_3\).

• Element 3 uses \(T_3,T_4\).

• Element 4 uses \(T_4,T_5\).

• Linear shape functions:

• The temperature approximation is linear within each element.

• The resulting plotted temperature field consists of straight-line segments between nodes.

• A finer mesh or higher-order elements can better represent a nonlinear temperature profile.

• Global stiffness matrix:

• The four equal linear elements produce a tridiagonal global matrix.

• Interior nodes receive contributions from two neighbouring elements.

• Boundary nodes receive a contribution from only one element.

• Internal source contribution:

• For the constant source used in the example, each element contributes 12.5 to each of its two local forcing-vector entries.

• When assembled, interior nodes receive two contributions, giving 25.

• End nodes receive one contribution, giving 12.5.

• Gradient cancellation:

• The gradient contribution at an internal node appears with opposite signs in the two adjacent element equations.

• These terms cancel when the element forcing vectors are assembled.

• The gradients at the two external boundaries remain as unknown boundary terms unless specified by boundary conditions.

• Boundary conditions:

• A no-flux condition sets the relevant temperature gradient to zero.

• A Dirichlet condition specifies the temperature directly and requires substitution and rearrangement of the associated equations.

• The lecture applies \(T_1=T_A=40\) and \(T_5=T_B=200\).

• Weak form:

• The second derivative in the governing equation is reduced to a first derivative through integration by parts.

• This allows the use of linear shape functions, whose second derivatives would otherwise be problematic or zero within each element.

• Method of weighted residuals:

• The residual is multiplied by each weighting function and integrated over the element.

• The integral is required to vanish for each local degree of freedom.

• Discretisation error:

• The true solution \(T\) and the finite-element approximation \(\widetilde{T}\) are not necessarily identical.

• With linear elements, a nonlinear temperature field is approximated by piecewise-linear segments.

• Reducing the element size should bring \(\widetilde{T}\) closer to \(T\).
