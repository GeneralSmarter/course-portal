Overview

This lecture completes the transition from individual bar elements to a solvable finite-element model of an entire structure.

The main progression is:

1. Recap local and global coordinate systems for bar elements.

2. Transform element stiffness matrices from local to global coordinates.

3. Introduce the assembly matrix to represent element connectivity and supports.

4. Assemble the global stiffness matrix and global force vector.

5. Solve for the structural degrees of freedom.

6. Use post-processing to determine element forces and support reactions.

The lecture emphasises that an individual element equation is insufficient because it does not contain information about how elements connect to one another or to supports. The assembly matrix supplies this missing connectivity information.

The lecture also reinforces that the transformation matrix and assembly matrix are different objects, despite their similar notation.

Key concepts

• Degrees of freedom (DOFs)

• A fully constrained point has no permissible displacement DOFs.

• A free node in a two-dimensional bar model may have horizontal and vertical displacement DOFs.

• Lowercase displacement quantities and uppercase applied-force quantities are paired by subscript, for example:

• \(q_1\): displacement associated with DOF 1.

• \(Q_1\): corresponding applied load.

• Local and global coordinates

• Local element coordinates are aligned with the element.

• Global coordinates are fixed to the overall structure.

• For a two-node, two-dimensional bar element:

• Local displacement vector: typically two axial displacement components.

• Global displacement vector: typically four components, two at each node: \(x\)- and \(y\)-direction displacements.

• The local coordinate system is usually defined with the local \(x\)-axis along the element from node 1 to node 2.

• Transformation angle

• The element orientation is described by an angle \(\alpha\), measured from the chosen global \(x\)-axis according to the course convention.

• The lecture states that the convention is to start aligned with the global \(x\)-axis and rotate counterclockwise until aligned with the element.

• Equivalent angles, such as \(-90^\circ\) and \(270^\circ\), may represent the same orientation.

• The selected convention must remain consistent when assigning local DOFs, global DOFs, and transformation matrices.

• Transformation matrix

• The transformation matrix maps quantities between local and global coordinate systems.

• For the element stiffness matrix, the global-coordinate stiffness matrix is obtained by pre-multiplying by the transpose of the transformation matrix and post-multiplying by the transformation matrix:

\[

\hat{k}_e = \Lambda_e^{T} k_e \Lambda_e

\]

• The exact placement of the transpose depends on the course’s definition of \(\Lambda_e\). The transcript consistently describes the stiffness transformation as “pre-multiply by the transpose and post-multiply by the transformation matrix.”

• The transformation matrix is rectangular rather than square in the local-to-global displacement mapping discussed in the lecture. Therefore, an ordinary matrix inverse does not exist.

• The transpose is used for the reverse mapping because of the structure of the coordinate transformation and the orthogonality of the direction-cosine terms.

• Direction cosines

• The transformation uses \(\cos\alpha\) and \(\sin\alpha\).

• A global displacement can be resolved into components parallel and perpendicular to the element.

• For a displacement magnitude \(d\), its components involve terms of the form:

\[

d\cos\alpha,\qquad d\sin\alpha

\]

• Assembly matrix

• The assembly matrix maps element quantities into the corresponding locations in the structural system.

• It contains only zeros and ones for the bar-element formulation presented.

• A one indicates that an element DOF corresponds to a particular global structural DOF.

• A zero indicates no correspondence.

• The assembly matrix does not scale quantities; it assigns them to locations.

• Zero columns can indicate element DOFs associated with fully constrained structural locations.

• Assembly matrix dimensions

• The number of columns equals the number of element DOFs expressed in global coordinates.

• For the two-dimensional bar element used in the lecture, this is four columns.

• The number of rows equals the total number of structural global DOFs in the particular problem.

• Consequently, the number of rows varies with the structure and its constraints.

• Connectivity

• The assembly matrix introduces information about:

• Which elements meet at a node.

• Which element DOFs correspond to the same structural DOFs.

• Which DOFs are constrained by supports.

• This connectivity information is required to combine individual element equations into a system equation for the whole structure.

• Global stiffness matrix

• Each element contributes a global-coordinate stiffness matrix to the overall structure.

• The global stiffness matrix is the sum of the assembled element contributions:

\[

K_g = \sum_e A_e \hat{k}_e A_e^T

\]

• Here:

• \(A_e\) is the assembly matrix for element \(e\).

• \(\hat{k}_e\) is the element stiffness matrix in global coordinates.

• \(K_g\) represents the complete structure.

• The global matrix includes element material properties, geometry, orientations, connectivity, and support information.

• Global force vector

• Element force vectors can be assembled into the structural force vector using the assembly matrices:

\[

Q = \sum_e A_e \hat{f}_e

\]

• At a shared node, the assembled force is the sum of the relevant internal element forces.

• This expresses nodal equilibrium: the sum of internal element contributions equals the applied external load.

• Solving the structure

• Once the global stiffness matrix and global force vector have been formed, the structural equation is solved:

\[

K_g q = Q

\]

• If \(K_g\) is nonsingular, the displacement vector may formally be written as:

\[

q = K_g^{-1}Q

\]

• In implementation, a linear-system solver such as NumPy’s solve function is preferable to explicitly calculating the inverse.

• The matrix solution simultaneously determines all unknown structural DOFs.

• Singular versus full-rank systems

• Before connectivity and support information are correctly included, the system may be singular and lack a unique solution.

• Correct assembly and sufficient constraints produce a full-rank system with a unique solution.

• An unconstrained rigid-body motion can also lead to singularity. The transcript does not explicitly develop this case, so the exact interpretation should be checked against course material.

• Post-processing

• Solving the global system gives structural displacements.

• Further calculations can determine:

• Element displacements in local coordinates.

• Element forces.

• Strains and stresses.

• Load distribution through the structure.

• Support reactions.

• Free-body diagrams

• Free-body diagrams of individual elements are used to interpret calculated element forces and determine support reactions.

• The lecturer states that free-body diagrams are important both for assessment marks and for understanding whether the computed results make physical sense.

Detailed notes

The lecture begins by positioning the topic within the finite-element workflow. Previous lectures derived the stiffness matrix for a single bar element and developed a transformation method for elements at arbitrary orientations. The missing step is connecting multiple elements into one structure and representing their connections to supports.

A fully constrained node cannot move, so it contributes no unknown displacement DOFs. At a node that can move horizontally and vertically, two displacement DOFs are assigned. The corresponding applied loads use matching subscripts. The lecturer stresses that the DOF assignments may need to be chosen by the student in a test rather than being supplied.

For an element whose local axes are aligned with the global axes, the coordinate transformation becomes simple. At \(\alpha=0^\circ\), cosine terms become 1 and sine terms become 0. The transformation matrix then mainly reassigns the local element quantities to their global locations.

For an element oriented vertically or at another angle, the transformation matrix includes direction-cosine terms. The lecturer uses a vertical example and discusses equivalent positive and negative angle descriptions. The important point is not the particular numerical angle but the consistency of the convention. The element local \(x\)-axis must be identified, and the direction from local node 1 to local node 2 must be used consistently.

The lecture explains the difference between transforming a global displacement vector into local element coordinates and transforming a local vector into global coordinates. The local vector is obtained by resolving global components along the element axes. The reverse operation is represented using the transpose of the transformation matrix in the course formulation.

The lecturer addresses why the inverse is not used. The transformation matrix discussed for mapping the four global displacement components to two local axial components is rectangular, so it has no ordinary inverse. The transpose is obtained by interchanging rows and columns and produces the required component relations using the direction cosines.

The element stiffness matrix in local coordinates is already known from earlier derivations. Instead of manually typing the resulting four-by-four global matrix, the lecturer recommends performing the matrix multiplication in Python. This reduces transcription errors and allows the same procedure to be used for arbitrary element orientations.

The lecture then returns to a multi-element structure. Each element has local DOFs and global-coordinate element DOFs. For a two-dimensional bar element, the global-coordinate element displacement vector has four entries. These correspond to the \(x\)- and \(y\)-direction displacement components at the element’s two nodes.

The transformation matrix automatically maps these element quantities into the appropriate global-coordinate positions. For an element aligned with a global axis, the entries may simply be reassigned or negated. For an arbitrarily inclined element, the mapping combines displacement components through sine and cosine terms.

At this point, the individual element equations are still independent. They contain the element’s geometry and material information, but not its structural connectivity. The assembly matrix is introduced to provide this information.

To construct an assembly matrix, the element global DOFs are listed across the columns and the global structural DOFs are listed down the rows. A one is placed where an element DOF corresponds to a structural DOF. All other entries are zero. Each element has its own assembly matrix because its local nodes connect to different structural nodes.

The lecture’s example includes constrained locations. Element DOFs that correspond to fully constrained support locations have no matching free structural DOF, producing all-zero columns. These all-zero columns encode the fact that the corresponding element DOF cannot produce a permissible structural displacement.

The assembly matrix contains only zeros and ones because the element DOFs expressed in global coordinates either match a structural DOF or do not. The matrix does not perform geometric scaling. Geometric rotation and component scaling are handled by the transformation matrix.

The element contribution to the global stiffness matrix is assembled using:

\[

K_{g,e}=A_e\hat{k}_eA_e^T

\]

The total global stiffness matrix is the sum of all element contributions:

\[

K_g=\sum_eK_{g,e}

\]

The same assembly matrices combine element force vectors into the global force vector. If two elements meet at a node, the forces associated with the matching structural DOF are added. The resulting value is the applied external load at that DOF. If no external load is applied, the assembled sum is zero, expressing equilibrium.

The lecturer distinguishes the symbols used for the assembly matrix and the transformation matrix. They may look similar in textbooks, but they have different purposes:

• The transformation matrix changes the coordinate representation of an element quantity.

• The assembly matrix maps element quantities into structural locations and combines connected contributions.

The global stiffness matrix is square. Its dimension is equal to the number of global structural DOFs included in the system. The example simplifies the algebra by assuming both elements have equal Young’s modulus, cross-sectional area, and length:

\[

E_1=E_2=E,\qquad A_1=A_2=A,\qquad L_1=L_2=L

\]

This assumption is specific to the worked example and is not a general requirement of the method.

After assembly, the global system is solved for the structural displacement vector. The lecturer identifies this matrix solution as the point at which the finite-element system is considered solved. All structural DOFs are obtained simultaneously.

The remaining calculations are post-processing. To recover the displacement vector for a particular element, the relevant global displacement components are extracted using the transpose of the element’s assembly matrix:

\[

d_e=A_e^Tq

\]

The element force vector can then be calculated using the element stiffness matrix in global coordinates:

\[

\hat{f}_e=\hat{k}_ed_e

\]

or, with the extraction written explicitly:

\[

\hat{f}_e=\hat{k}_eA_e^Tq

\]

Element forces can be related to free-body diagrams to determine support reactions. The assembly matrix avoids manually extracting each relevant displacement from the global vector.
