One-dimensional transient heat equation

The example considered a rod with:

• Constant cross-sectional area, A.

• Uniform material properties.

• A fully insulated outer boundary.

The insulation assumption means there is no heat transfer between the rod and the surrounding air through the outer surface. This allows the temperature to be modelled as a function of only x and t.

Consider a differential element between x and x + Δx. The element has length Δx and volume:

V = A Δx

The energy balance is:

• Heat accumulation per unit time = heat entering − heat leaving.

The heat stored in the element is proportional to:

ρ c V T

where:

• ρ is density.

• c is specific heat capacity.

• V is volume.

• T is temperature.

The rate of heat accumulation is therefore:

ρ c A Δx ∂T/∂t

Let the heat rate entering at x be Q̇(x,t) and the heat rate leaving at x + Δx be Q̇(x + Δx,t).

The energy balance is:

ρ c A Δx ∂T/∂t = Q̇(x,t) − Q̇(x + Δx,t)

Using a first-order Taylor expansion about x:

Q̇(x + Δx,t) ≈ Q̇(x,t) + (∂Q̇/∂x) Δx

Substitution gives:

ρ c A Δx ∂T/∂t = −(∂Q̇/∂x) Δx

After cancelling Δx:

ρ c A ∂T/∂t = −∂Q̇/∂x

Fourier’s law in one dimension is:

Q̇ = −k A ∂T/∂x

where k is thermal conductivity.

Substituting Fourier’s law into the energy balance gives:

ρ c A ∂T/∂t = ∂/∂x (k A ∂T/∂x)

For constant k and constant A:

ρ c A ∂T/∂t = k A ∂²T/∂x²

After cancelling A:

ρ c ∂T/∂t = k ∂²T/∂x²

Define thermal diffusivity as:

α = k/(ρ c)

The one-dimensional transient heat equation is then:

∂T/∂t = α ∂²T/∂x²

The transcript uses “heat diffusivity” or “thermal diffusivity” for α.

The equation contains:

• A first-order time derivative on the left.

• A second-order spatial derivative on the right.

• Diffusion of temperature in space.

• Time-dependent temperature evolution.

A larger thermal diffusivity corresponds to faster spreading of temperature differences, all else being equal.

Dimensional analysis

The units of temperature are kelvin, and the units of time are seconds. Therefore:

[∂T/∂t] = K/s

For the spatial term:

[∂²T/∂x²] = K/m²

For dimensional consistency:

[α] (K/m²) = K/s

Therefore:

[α] = m²/s

Thermal diffusivity has units of square metres per second and can be interpreted as a diffusion-rate coefficient.

Other PDE terms

The lecturer noted that more complex physical models can contain additional terms.

Examples include:

• Source terms, such as heat generated by chemical reactions.

• Convective or advective terms in fluid mechanics.

• Additional terms in the Navier–Stokes equations.

The example in this lecture considered temperature variation due only to diffusion.

Separation of variables for the heat equation

The heat equation was solved using separation of variables. Assume:

T(x,t) = F(x)G(t)

where:

• F(x) depends only on position.

• G(t) depends only on time.

The derivatives are:

∂T/∂t = F(x) dG/dt

and:

∂²T/∂x² = G(t) d²F/dx²

Substitution into the heat equation gives:

F dG/dt = α G d²F/dx²

Divide by αFG:

(1/(αG)) dG/dt = (1/F) d²F/dx²

The left-hand side depends only on time, while the right-hand side depends only on position. They can therefore be equal for all x and t only if both are equal to a constant.

For the physically useful case, choose the separation constant as:

−λ²

This gives the two ordinary differential equations:

(1/(αG)) dG/dt = −λ²

and:

(1/F) d²F/dx² = −λ²

Equivalently:

dG/dt = −αλ²G

and:

d²F/dx² + λ²F = 0

The temporal solution is:

G(t) = C exp(−αλ²t)

The spatial solution is of the form:

F(x) = A cos(λx) + B sin(λx)

The positive separation-constant case would generate an exponentially growing temporal term, proportional to:

exp(+αλ²t)

The lecturer described this as unstable and generally unsuitable for ordinary diffusion, because temperature differences normally decay and become more uniform with time.

The complete separated solution for a given mode is therefore of the form:

T_n(x,t) = B_n sin(λ_n x) exp(−αλ_n²t)

for boundary conditions that select sine modes.

Because the PDE is second order in space and first order in time, a solution requires:

• Two spatial boundary conditions.

• One initial condition.

Copper-bar example

• Length: 80 cm.

The initial profile was given as:

The units of x must be used consistently with the units of the bar length and thermal diffusivity.

The boundary conditions are:

T(0,t) = 0

and:

T(80,t) = 0

for all time.

Using the general spatial form:

F(x) = A cos(λx) + B sin(λx)

the left boundary condition gives:

F(0) = A = 0

because cos(0) = 1 and sin(0) = 0.

The right boundary condition then requires:

sin(λ 80) = 0

for a non-trivial solution. Therefore:

λ_n = nπ/80

where:

n = 1, 2, 3, ...

The individual modes are:

T_n(x,t) = B_n sin(nπx/80) exp(−α(nπ/80)²t)

By linear superposition, the general solution is:

T(x,t) = Σ B_n sin(nπx/80) exp(−α(nπ/80)²t)

The initial condition contains only the first sine mode:

T(x,0) = 100 sin(πx/80)

Therefore:

• B_1 = 100

• B_2 = B_3 = ... = 0

The solution reduces to:

T(x,t) = 100 sin(πx/80) exp(−α(π/80)²t)

The maximum temperature remains at the centre of the bar because:

sin(πx/80)

has its maximum at:

x = 40 cm

The maximum temperature therefore satisfies:

T_max(t) = 100 exp(−α(π/80)²t)
