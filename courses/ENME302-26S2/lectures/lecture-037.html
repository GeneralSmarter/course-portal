Key concepts

• A separated solution to a transient heat equation should have the time dependence inside a decaying exponential when modelling cooling or diffusion. A positive coefficient in the exponential produces growth rather than decay.

• For a backward-in-time, central-in-space scheme, the spatial derivative terms are evaluated at the new time level, commonly written as \(n+1\).

• A three-dimensional heat-transfer problem can be reduced to one dimension when:

• the geometry and boundary conditions imply no variation in two directions;

• the side boundaries are thermally insulated;

• the heat source is uniform;

• heat transfer occurs only from the base toward the top.

• A thermally insulated boundary is represented by zero normal heat flux, or a homogeneous Neumann condition.

• The COMSOL heat-transfer-in-solids interface uses material properties including density, heat capacity, and thermal conductivity.

• Finite difference methods use values on a structured set of grid points and can become inconvenient for irregular geometries, complex boundaries, or spatially varying material properties.

• Finite element methods divide a domain into elements defined by nodes. The dependent variable is interpolated inside each element from its nodal values.

• Finite element governing equations are imposed in a weak or integrated sense rather than necessarily being satisfied pointwise inside every element.

• Shape functions weight the nodal values to reconstruct the approximate field within an element.

• Linear one-dimensional shape functions have the Kronecker-delta property:

• each shape function equals 1 at its associated node;

• each shape function equals 0 at the other node.

• Element equations are formed locally and then assembled into a global system.

• Assembly requires continuity of the dependent variable across adjacent element boundaries.

• Mesh refinement reduces discretisation error and helps assess mesh convergence.

• Finite element methods are particularly flexible for generic geometries and unstructured meshes.

Finite difference versus finite element methods

Finite difference methods:

• discretise the domain into grid points;

• approximate derivatives using finite-difference formulas;

• work naturally with structured, mapped grids;

• can become difficult for irregular boundaries;

• can become more complicated for complex boundary conditions;

• require additional care when material properties vary throughout the domain.

Finite element methods:

• divide the domain into finite subdomains called elements;

• define each element using a topology of nodes;

• support unstructured meshes;

• handle generic geometries more naturally;

• interpolate the dependent variable inside each element;

• impose the governing PDE in a weak or integrated sense.

Finite elements are commonly used in solid mechanics. They can also be used in fluid mechanics and computational fluid dynamics, although finite volume methods are often used for CFD.

Finite element discretisation

A finite element model contains:

• a physical domain;

• a mesh of elements;

• nodes defining the elements;

• nodal values of the dependent variables;

• interpolation or shape functions;

• element-level equations;

• a global assembled system;

• boundary conditions;

• a numerical solution and post-processing procedure.

The dependent variable could be:

• temperature \(T\);

• displacement \(U\);

• velocity components \(U\) and \(V\);

• pressure \(P\);

• electric potential;

• another field variable.

In one dimension, the domain is divided into line elements. In two dimensions, common element types include:

• triangular elements;

• quadrilateral elements;

• higher-order elements.

The lecturer used an example with a one-dimensional interval from \(x=0\) to \(x=L\), divided into four line elements. Nodes occur at the boundaries between elements. Within each element, the dependent variable is approximated using an interpolation function.

The order of the interpolation may be:

• linear;

• quadratic;

• cubic.

Higher-order interpolation can represent variation within an element more accurately, but the quality of the result also depends on mesh resolution and the problem being solved.

The lecturer related this to finite element stress results. With a coarse mesh or coarse plotted representation, peak von Mises stress may appear different because the field is interpolated from nodal values. Refining the mesh produces a more resolved estimate of local peaks.

Linear one-dimensional interpolation

For an element extending from \(x_1\) to \(x_2\), assume the dependent variable varies linearly:

\[

u(x)=A_0+A_1x

\]

The nodal values are:

\[

u_1=u(x_1)

\]

\[

u_2=u(x_2)

\]

Substitution of the two nodal coordinates gives two equations for the two unknown coefficients \(A_0\) and \(A_1\):

\[

u_1=A_0+A_1x_1

\]

\[

u_2=A_0+A_1x_2

\]

Solving gives:

\[

A_0=\frac{u_1x_2-u_2x_1}{x_2-x_1}

\]

\[

A_1=\frac{u_2-u_1}{x_2-x_1}

\]

The resulting interpolation can be written in terms of shape functions:

\[

u(x)=N_1(x)u_1+N_2(x)u_2

\]

where:

\[

N_1(x)=\frac{x_2-x}{x_2-x_1}

\]

\[

N_2(x)=\frac{x-x_1}{x_2-x_1}

\]

The shape functions vary linearly across the element:

• \(N_1\) decreases from 1 at \(x_1\) to 0 at \(x_2\);

• \(N_2\) increases from 0 at \(x_1\) to 1 at \(x_2\).

They satisfy:

\[

N_1(x_1)=1,\qquad N_1(x_2)=0

\]

\[

N_2(x_1)=0,\qquad N_2(x_2)=1

\]

These properties ensure that the interpolated field reproduces the correct nodal values.

Derivative of the linear interpolation

Differentiating the interpolation:

\[

\frac{du}{dx}

=

\frac{dN_1}{dx}u_1+

\frac{dN_2}{dx}u_2

\]

The shape-function derivatives are:

\[

\frac{dN_1}{dx}=-\frac{1}{x_2-x_1}

\]

\[

\frac{dN_2}{dx}=\frac{1}{x_2-x_1}

\]

Therefore:

\[

\frac{du}{dx}

=

\frac{u_2-u_1}{x_2-x_1}

\]

For a linear element, the derivative is constant throughout the element. It is simply the rise over the run.

Integral of the linear interpolation

The integral over one element is:

\[

\int_{x_1}^{x_2}u(x)\,dx

=

\int_{x_1}^{x_2}

\left[N_1(x)u_1+N_2(x)u_2\right]dx

\]

Because \(u_1\) and \(u_2\) are constant with respect to \(x\):

\[

\int_{x_1}^{x_2}u(x)\,dx

=

u_1\int_{x_1}^{x_2}N_1(x)\,dx

+

u_2\int_{x_1}^{x_2}N_2(x)\,dx

\]

Each shape function forms a triangle over the element. Hence:

\[

\int_{x_1}^{x_2}N_1(x)\,dx

=

\frac{x_2-x_1}{2}

\]

\[

\int_{x_1}^{x_2}N_2(x)\,dx

=

\frac{x_2-x_1}{2}

\]

Thus:

\[

\int_{x_1}^{x_2}u(x)\,dx

=

\frac{x_2-x_1}{2}(u_1+u_2)

\]

This is equivalent to applying the trapezoidal rule to a linearly interpolated field.

Element equations and assembly

After selecting the interpolation functions, the nodal values must be determined so that the approximate solution satisfies the governing PDE.

The method of residuals was previewed as the next step. For each element, the procedure produces a local system such as:

\[

\mathbf{K}^{(e)}\mathbf{U}^{(e)}

=

\mathbf{F}^{(e)}

\]

where:

• \(\mathbf{K}^{(e)}\) is the element stiffness matrix;

• \(\mathbf{U}^{(e)}\) is the vector of element nodal unknowns;

• \(\mathbf{F}^{(e)}\) is the element forcing or right-hand-side vector.

For a two-node one-dimensional element, there are two nodal unknowns and therefore two corresponding element equations.

The local element systems are assembled into a global system:

\[

\mathbf{K}^{G}\mathbf{U}^{G}

=

\mathbf{F}^{G}

\]

The assembly process links adjacent elements. A shared node must have one consistent global value. For example, a nodal temperature at the interface between two elements cannot take different values in the two elements.

The dependent variable must be continuous across element boundaries. Depending on the formulation, derivative continuity may also be enforced or may arise through the chosen approximation and governing equations.

Boundary conditions are applied after assembling the global equations. The resulting system is then solved using a numerical linear-system method. The lecturer referred to a method used earlier in the course, but the automated transcript renders its name uncertain. COMSOL uses more advanced solver algorithms internally.

Finally, the nodal solution is interpolated within each element to plot the field throughout the domain.
