Key concepts

• Laplace’s equation describes a harmonic field:

\[

\nabla^2 u = 0

\]

• Separation of variables produces several possible general solution forms. The appropriate form depends on:

• The domain geometry.

• The boundary conditions.

• Whether the solution must decay, remain bounded, or satisfy zero conditions.

• Boundary conditions equal to zero are especially useful because they eliminate coefficients or restrict the separation constant to discrete eigenvalues.

• For a rectangular domain with zero conditions at \(y=0\) and \(y=1\), sine functions of the form

\[

\sin(n\pi y)

\]

satisfy the vertical boundary conditions.

• If the domain extends to \(x\to\infty\) and the field must decay, the growing exponential \(e^{n\pi x}\) must be discarded.

• A constant boundary value cannot generally be represented by one sine mode. It is represented using a Fourier sine series.

• Linear superposition allows the individual separated solutions to be summed to satisfy a more complicated boundary condition.

• Higher-order Fourier terms contribute progressively smaller effects, but a finite truncation only approximates the exact infinite series.

• Analytical solutions should be checked by:

• Substitution into Laplace’s equation.

• Substitution into every boundary condition.

• Qualitative inspection of plots, including decay and boundary behaviour.

• For numerical plotting:

• A continuous domain is discretised into grid points.

• If there are \(N\) intervals, there are \(N+1\) grid points.

• meshgrid-type functions generate coordinate matrices.

• Surface and contour plots visualise scalar fields.

• The gradient can be plotted using vector arrows such as a quiver plot.

Equations and definitions

Laplace’s equation

For a two-dimensional scalar field \(u(x,y)\):

\[

\frac{\partial^2u}{\partial x^2}

+

\frac{\partial^2u}{\partial y^2}

=0

\]

Separated solution structure

A separated solution assumes:

\[

u(x,y)=X(x)Y(y)

\]

Depending on the separation constant and boundary conditions, the resulting forms can include:

\[

u(x,y)=

\left(Ae^{\mu x}+Be^{-\mu x}\right)

\left(C\sin(\mu y)+D\cos(\mu y)\right)

\]

or equivalent forms with the \(x\)- and \(y\)-dependence interchanged.

Hyperbolic-sine identity

\[

\sinh z=\frac{e^z-e^{-z}}{2}

\]

Therefore:

\[

e^{n\pi x}-e^{-n\pi x}

=

2\sinh(n\pi x)

\]

Discrete eigenvalues from zero boundaries

If:

\[

\sin(\mu)=0

\]

then:

\[

\mu=n\pi,\qquad n=1,2,3,\ldots

\]

The \(n=0\) case was excluded for the non-zero separation-constant solution being used.

The superposed solution is:

\[

u(x,y)

=

\sum_{n=1}^{\infty}

The Fourier sine coefficients for the constant left boundary are:

\[

C_n=

\begin{cases}

\dfrac{4}{n\pi}, & n=1,3,5,\ldots\\[6pt]

\end{cases}

\]

Thus:

\[

u(x,y)

=

\frac{4}{\pi}

\sum_{\substack{n=1\\n\text{ odd}}}^{\infty}

\frac{1}{n}

e^{-n\pi x}

\sin(n\pi y)

\]

Grid-point count

If the spacing in one direction is \(\Delta x\) and the domain length is \(L_x\), then:

\[

N_x=\frac{L_x}{\Delta x}

\]

is the number of intervals, while the number of grid points is:

\[

N_{x,\text{points}}=N_x+1

\]

The same applies in the \(y\)-direction.
