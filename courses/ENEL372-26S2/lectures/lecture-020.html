Key concepts

• A rectifier converts an AC waveform into a unidirectional, pulsating output.

• A single-phase half-wave rectifier uses only one half-cycle of the AC waveform.

• A half-wave rectifier produces two pulses over two input periods, or one output pulse per input period.

• A three-phase rectifier produces more pulses than a single-phase rectifier. The lecture identifies six pulses per period for a three-phase supply and twelve pulses per period for a six-phase supply.

• More pulses produce a higher ripple frequency, making filtering easier.

• Higher-frequency ripple can generally be filtered using smaller capacitors and other smaller filter components.

• An ideal diode has zero forward voltage in the lecture analysis. A practical diode has a forward drop, stated as approximately 0.8 V for the example discussed.

• A capacitor smooths the rectified waveform by reducing voltage variation.

• A good rectifier should produce an output voltage that is as constant as possible and should not vary greatly when the load changes.

• Rectifier performance has both a DC-side aspect and an AC-side aspect:

• DC side: how close the output is to constant DC.

• AC side: how closely the input current resembles a sinusoid.

• Ripple is the time-varying component remaining after the average DC component has been removed.

• RMS calculations emphasise large waveform excursions because the waveform is squared.

• Effectiveness of rectification is a measure of how much of the output power is useful DC power compared with total rectified power. It is not the same as ordinary circuit efficiency based on losses.

• Ripple factor is a normalised measure of the AC ripple relative to the average DC output.

• A rectifier can draw a highly distorted current from an otherwise sinusoidal AC supply.

• Total harmonic distortion measures the difference between the actual current waveform and its fundamental sinusoidal component.

• Total power factor depends on both waveform distortion and phase displacement.

Basic half-wave rectifier

The simplest circuit considered consists of:

• An AC voltage source.

• An ideal diode.

• A resistive load.

During the conducting half-cycle, the diode allows current to flow through the load. During the opposite half-cycle, the diode blocks current, so the load voltage and current are zero.

The output therefore contains only one half of the original sinusoid. The negative half-cycle is removed rather than inverted.

This is a rectifier, but a poor one because:

• Half of the input waveform is unused.

• The output contains large gaps.

• The output has significant ripple.

• The output is difficult to use as a constant DC supply.

• The input current and output voltage are highly non-sinusoidal or distorted.

• For an LED application, the lecture states that approximately half of the available power is lost by using only one half-cycle, resulting in a relatively dim output.

The lecture also discusses the diode forward-voltage drop. In the ideal-diode analysis this drop is ignored. For a practical diode, the peak output would be approximately:

\[

V_{\text{out,peak}} \approx V_{\text{s,peak}} - V_D

\]

The transcript gives approximately \(V_D = 0.8\text{ V}\) as a representative value. This voltage drop reduces the output voltage and causes power loss, which is especially relevant in applications such as the solar car.

Nonlinearity and distortion

A linear system supplied with a sinusoidal input produces a sinusoidal output, although the amplitude and phase may change.

A nonlinear system can produce an output that is not sinusoidal even when the input is sinusoidal. The diode rectifier is nonlinear because its conduction state changes depending on the polarity of the input voltage.

The half-wave rectifier therefore produces:

• A non-sinusoidal output voltage.

• A non-sinusoidal input current.

• Distortion and harmonic components.

• A low-frequency pulsating output that is difficult to filter.

The lecturer warns that widespread use of devices with distorted current demand could create transients or other undesirable effects in the electrical grid.

RC load and filtering

The lecture then considers an RC load consisting of:

• A rectifier.

• A capacitor.

• A resistive load.

The capacitor is used to filter the rectified waveform. It charges when the rectifier output rises and discharges through the load between conduction intervals.

The same basic filtering principle was used in the solar-car circuit, where a capacitor reduced voltage variation caused by fast MOSFET switching.

For each selected load resistance, the lecture proposes measuring or calculating:

• The average output voltage.

• The RMS load current.

• The resulting output waveform.

• The way these quantities change with load resistance.

The lecturer describes using LTspice to inspect voltage and current waveforms and to obtain average and RMS values.

Load regulation

A useful rectifier should maintain a reasonably constant output voltage as the load changes.

Changing the resistance changes the load current. The lecture describes plotting average output voltage against load current to characterise the rectifier.

The ideal behaviour would be a nearly horizontal relationship:

\[

V_{\text{out,average}} \approx \text{constant}

\]

In the simulated example:

• Low resistance produces a heavier load.

• The output voltage has larger fluctuations at low resistance.

• Increasing resistance reduces the visible fluctuations.

• The output voltage still varies with load, indicating poor regulation.

The lecturer describes large voltage variation with load as bad regulation. A practical power supply should not change substantially merely because the load changes.

Average and RMS values

The average value of a periodic waveform is obtained by integrating over one period and dividing by the period:

\[

V_{\text{avg}} = \frac{1}{T}\int_0^T v(t)\,dt

\]

For a half-wave waveform, the output is zero during the non-conducting half-cycle. Therefore, the integral only has a non-zero contribution during the conducting interval.

The lecture uses a unit-amplitude half-wave sinusoid as an illustrative example and derives an average value proportional to:

\[

\frac{1}{\pi}

\]

For a half-wave-rectified sinusoid with peak value \(V_m\), the corresponding standard result is:

\[

V_{\text{avg}} = \frac{V_m}{\pi}

\]

Fourier-series interpretation

The rectifier output can be separated conceptually into:

\[

v(t) = V_{\text{DC}} + v_{\text{ripple}}(t)

\]

where:

• \(V_{\text{DC}}\) is the average component.

• \(v_{\text{ripple}}(t)\) is the time-varying component around the average.

A Fourier series represents the ripple as a sum of harmonic terms. The lecturer notes that:

• The average value represents the desired constant component.

• The remaining harmonic terms represent ripple.

• Truncating the Fourier series to a limited number of harmonics can still give a useful approximation.

Effectiveness of rectification

The lecture defines an effectiveness measure based on comparing ideal DC power with the total power associated with the rectified waveform.

For an ideal constant DC output across a resistive load:

\[

P_{\text{DC}} = \frac{V_{\text{avg}}^2}{R}

\]

For the actual waveform, using the RMS voltage:

\[

P_{\text{AC,total}} = \frac{V_{\text{RMS}}^2}{R}

\]

The effectiveness of rectification is described as the ratio:

\[

\eta_{\text{rect}} =

\frac{P_{\text{DC}}}{P_{\text{AC,total}}}

=

\frac{V_{\text{avg}}^2}{V_{\text{RMS}}^2}

\]

For a perfectly constant DC waveform:

\[

V_{\text{RMS}} = V_{\text{avg}}

\]

so:

\[

\eta_{\text{rect}} = 1

\]

A lower value indicates that more of the waveform power is associated with ripple rather than the desired DC component.

This is not ordinary efficiency. It does not directly represent power lost as heat in the diode or other components. It measures the quality of the rectified waveform.

Ripple power and RMS decomposition

The lecturer explains that the total RMS power can be viewed as containing:

• Desired DC power.

• Ripple power.

The ripple component is obtained after removing the DC offset from the waveform:

\[

v_{\text{ripple}}(t) = v(t) - V_{\text{avg}}

\]

The lecture states that RMS quantities are based on sums of squares. Consequently, the total mean-square quantity can be separated into the DC contribution and the ripple contribution:

V_{\text{RMS}}^2

=

V_{\text{avg}}^2

+

V_{\text{ripple,RMS}}^2

\]

for a ripple waveform with zero average.

This gives an intuitive interpretation of the effectiveness measure: increasing ripple increases the total RMS power without increasing the useful DC power.

Ripple factor

Ripple factor is introduced as a normalised measure of ripple magnitude.

The intuitive construction is:

1. Subtract the average DC value from the actual waveform.

2. Compute the RMS value of the remaining ripple.

3. Divide the ripple RMS value by the average output voltage.

Thus:

\[

r =

\frac{V_{\text{ripple,RMS}}}{V_{\text{avg}}}

\]

Using the RMS decomposition:

\[

V_{\text{ripple,RMS}}

=

\sqrt{V_{\text{RMS}}^2 - V_{\text{avg}}^2}

\]

Therefore:

\[

r =

\frac{\sqrt{V_{\text{RMS}}^2 - V_{\text{avg}}^2}}

{V_{\text{avg}}}

\]

or equivalently:

\[

r =

\sqrt{

\left(\frac{V_{\text{RMS}}}{V_{\text{avg}}}\right)^2 - 1

}

\]

The lecture emphasises why the average value appears in the denominator: a fixed ripple amplitude is relatively small on a large DC level but relatively large on a small DC level.

AC-side current distortion

The supply voltage is treated as an undistorted sinusoid, such as the 230 V RMS mains waveform. The rectifier can nevertheless draw a distorted current.

The current can be compared with its fundamental sinusoidal component:

\[

i(t) = i_1(t) + i_{\text{harmonics}}(t)

\]

The distortion component is the difference between the actual current and the fundamental current. Its RMS value measures how far the current is from a pure sine wave.

The lecture describes total harmonic distortion as comparing the current waveform with its fundamental rather than comparing a voltage waveform with a constant average value.

Total power factor

The lecture briefly distinguishes distortion from phase displacement.

A poor AC-side power factor can arise because:

• The current waveform is distorted.

• The fundamental current is phase-shifted relative to the supply voltage.

• Both effects occur simultaneously.

The power authorities dislike poor power factor because the supply system must carry additional current even when the useful real power is comparatively low. This can require larger conductors and transformers and increase system cost.
