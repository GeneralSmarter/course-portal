Overview

This lecture introduces the design of embedded closed-loop control systems for an electric motor driving a mechanical load. The focus is a brushed DC motor supplied by a buck converter, with nested feedback loops for:

• Torque, controlled through motor armature current.

• Speed, controlled by generating a torque reference.

• Position, controlled by generating a speed reference.

The lecture develops a simplified motor-and-load model, derives transfer-function blocks for the electrical and mechanical dynamics, and explains how a PI controller can be selected to obtain adequate stability and performance. The main design idea is to make the PI controller zero cancel the motor’s electrical pole, leaving a simpler open-loop system with a maximum phase shift of approximately −90°.

The lecture prioritises sufficiently stable and practical control rather than a fully optimised analytical design with minimum overshoot or maximum response speed.

Key concepts

• Closed-loop control compares a desired/reference value with a measured output.

• The difference between reference and measured output is the error.

• Feedback control uses the error to adjust the system input and reduce the error.

• Motor torque is directly proportional to armature current for the brushed DC motor model.

• Current sensing can therefore be used as a substitute for direct torque measurement.

• Speed and position require mechanical sensing, typically using a shaft or rotary encoder.

• Nested motor-control loops are arranged from fastest to slowest:

1. Inner torque/current loop.

2. Middle speed loop.

3. Outer position loop.

• The torque loop is fastest because power electronics can change motor voltage and current rapidly.

• The speed loop is slower because mechanical inertia limits acceleration.

• The position loop is slowest because the system must accelerate, approach the desired position, decelerate, and possibly correct overshoot.

• For the fast current-control loop, back EMF can be treated as approximately constant because motor speed changes much more slowly than current.

• A buck converter produces the motor voltage by adjusting its duty ratio.

• A PI controller is used for current/torque control.

• Integral action is required because a non-zero duty ratio is needed to maintain a non-zero armature current.

• Differential action is not included in the basic design because it is not considered necessary for sufficient torque-control performance.

• Stability risk occurs if the open-loop gain magnitude is approximately one when the phase shift approaches ±180°.

• The PI-controller zero is selected to cancel the motor’s electrical pole.

• Good control requires high loop gain over the intended operating-frequency range and low gain at high-frequency disturbances, including converter switching-frequency disturbances.

• The gain magnitude of one, or 0 dB, marks the approximate transition between strong tracking and attenuation.

• The −3 dB point is used to identify the closed-loop bandwidth.

• A phase margin of at least approximately 45° is presented as a practical target.

Detailed notes

Closed-loop motor control

A motor driving a mechanical load will commonly require feedback. Depending on the application, the controlled variable may be:

• Torque.

• Rotational speed.

• Mechanical position.

The system measures the relevant output, compares it with the desired or ordered value, and forms an error:

\[

e = \text{reference value} - \text{measured value}

\]

The controller processes this error and changes the electrical input to the motor so that the measured output approaches the reference. The error is expected to become acceptably small, but not necessarily exactly zero. The acceptable error depends on the application.

The control system should also be robust to:

• Measurement noise.

• Internal system variations.

• Changes in mechanical load.

• Large changes in the reference command, such as a step change in desired speed.

Nested torque, speed, and position loops

The basic embedded-control structure consists of nested loops.

#### Torque/current loop

Motor torque is directly proportional to armature current. Therefore, instead of directly measuring torque, the controller can measure motor current and compare it with an ordered current or torque reference.

The current error is sent to a torque/current controller. Its output controls the electrical system, which changes the motor voltage and therefore the armature current.

This is the inner loop and is the fastest loop in the system.

#### Speed loop

If speed control is also required, a mechanical sensor measures rotational speed. The measured speed is compared with the ordered speed. The speed error is processed by a speed controller.

The output of the speed controller is an ordered torque value, or equivalently an ordered current value because torque and current are proportional. This torque reference is passed to the inner torque/current loop.

The current loop then acts quickly to produce the requested torque, allowing the mechanical system to approach the desired speed.

#### Position loop

If position control is required, a rotary encoder or equivalent position sensor measures the mechanical position. The measured position is compared with the ordered position, and the error is processed by a position controller.

The position controller produces an ordered speed. The speed loop converts this into an ordered torque, and the torque/current loop produces the required motor torque.

The relationship between speed and position is integration:

\[

\theta(t) = \int \omega(t)\,dt

\]

In the complex-frequency domain, this corresponds to a factor of:

\[

\frac{1}{s}

\]

where \(s\) is the complex-frequency variable.

Different time scales of the control loops

The nested structure works because each loop has a different characteristic time scale.

• The power-electronic converter can change its output electrical state rapidly.

• Motor current, and therefore motor torque, can change rapidly.

• Mechanical speed changes more slowly because of the inertia of the motor and load.

• Position changes more slowly still because the system must move through a distance and manage acceleration and deceleration.

An outer loop therefore sees the dynamics of the inner loop as nearly instantaneous or non-dynamic, provided that the inner loop is sufficiently faster.

For example:

• The speed loop can treat the current/torque loop as effectively instantaneous.

• The position loop can treat the speed loop as relatively fast.

• The current loop can treat the back EMF as approximately constant because speed changes slowly in comparison.

• A DC source.

• A mechanical load with inertia and torque requirements.

The buck converter supplies the motor armature voltage. The gearbox couples the motor to the load and changes the relationship between motor-side and load-side speed, torque, and inertia.

Referring load inertia to the motor side

To simplify the mechanical model, the load inertia is referred through the gearbox to the motor side. The total effective inertia is then the motor inertia plus the load inertia referred to the motor shaft:

\[

J_{\text{total}} = J_M + J_{\text{load, referred}}

\]

The motor torque and load torque act in opposite directions. Their difference is the residual torque available to accelerate the combined effective inertia:

\[

T_{\text{residual}} = T_M - T_L

\]

Subject to sign conventions, the mechanical acceleration is:

\[

\frac{d\omega_M}{dt}

=

\frac{T_{\text{residual}}}{J_{\text{total}}}

Brushed DC motor electrical model

The motor input is the output voltage of the buck converter, denoted in the lecture as \(V_{BO}\) or a similar notation. The transcript’s notation is sometimes unclear, but it is intended to represent the buck-converter output voltage.

The armature is represented by:

• Armature resistance \(R_A\).

• Armature inductance \(L_A\).

• Back EMF \(E_A\).

The armature current is \(I_A\).

As the motor rotates, the armature conductors move through the stator magnetic field and generate back EMF. The magnitude of back EMF increases with motor speed.

The motor model assumes negligible losses for simplicity. The lecturer describes this as effectively assuming 100% motor efficiency for the model, while acknowledging that real motors have losses.

The back EMF is:

\[

E_A = K\omega_M

\]

where:

• \(K\) is the motor constant.

• \(\omega_M\) is motor angular speed.

The motor torque is:

\[

T_M = K I_A

\]

The same motor constant is used in both relationships in the lecture’s simplified model. In a more detailed treatment, the numerical units and distinction between torque and back-EMF constants may require attention.

V_{BO} - E_A

\[

V_{BO}(s) - E_A(s)

=

I_A(s)\left(R_A + sL_A\right)

Therefore:

\[

I_A(s)

\frac{V_{BO}(s)-E_A(s)}

{R_A+sL_A}

\tau_A = \frac{L_A}{R_A}

The corresponding motor electrical pole is associated with this time constant.

Mechanical transfer-function blocks

The motor torque is generated from armature current:

\[

T_M = K I_A

\]

This is represented by a gain block \(K\).

The residual torque accelerates the total effective inertia:

\[

\frac{d\omega_M}{dt}

=

\frac{T_M-T_L}{J_{\text{total}}}

\]

In the complex-frequency domain, integration of acceleration gives speed:

\[

\omega_M(s)

=

\frac{1}{s}

\frac{T_M(s)-T_L(s)}

{J_{\text{total}}}

\]

Thus, the mechanical dynamics include:

• A summing junction for motor torque and opposing load torque.

• A gain of \(1/J_{\text{total}}\).

• An integrator \(1/s\) to convert acceleration to speed.

The speed is fed through the motor constant \(K\) to produce back EMF:

\[

E_A = K\omega_M

\]

This back EMF acts as feedback into the electrical motor equation.

Buck converter model

For the simplified buck-converter model, the motor voltage is related to the source voltage and duty ratio by:

\[

V_{BO} = D V_S

\]

where:

• \(D\) is the converter duty ratio.

• \(V_S\) is the source voltage.

The current controller produces a command related to the required duty ratio. The power electronics then adjusts the duty ratio, changing \(V_{BO}\), which changes armature current.

PI current/torque control

The measured armature current is compared with the ordered armature current:

\[

e_I = I_{A,\text{ordered}} - I_A

\]

The current error is fed into a PI controller. The proportional term responds to the instantaneous error. The integral term accumulates error over time.

The integral term is important because maintaining a non-zero armature current generally requires a non-zero duty ratio even when the current error is zero. With proportional-only control:

• Zero steady-state current error would produce zero proportional-controller output.

• This would force the duty ratio toward zero.

• The converter output voltage would then fall toward zero.

• The armature current would also fall toward zero.

• The desired non-zero current could not be maintained.

The integral term stores the required duty-ratio command and maintains it when the measured current reaches the ordered current.

The proportional term reduces the residual current error. The lecture states that a small continuous residual error may remain in the practical system.

A standard PI-controller form is:

\[

G_{PI}(s)

=

K_P+\frac{K_I}{s}

\]

This can be written in pole-zero form as:

\[

G_{PI}(s)

=

\frac{K_I}{s}

\left(1+s\frac{K_P}{K_I}\right)

\]

The PI controller therefore has:

• An integrator pole at the origin.

• A zero associated with the ratio \(K_P/K_I\).

The transcript does not give a complete, unambiguous final expression for every gain factor in the controller, so the exact convention for \(K_P\) and \(K_I\) should be checked against the lecture slides.

Differential control could be added to reduce overshoot, but it is not used in the basic torque-control design because the objective is adequate operation and stability rather than maximum optimisation.

Open-loop gain and stability

The open-loop gain is found by multiplying the transfer-function blocks from controller input to output while omitting feedback.

For the current loop, the open-loop path includes:

1. The PI controller.

2. The buck converter.

3. The motor electrical dynamics.

The lecture treats the back EMF as static for this fast loop because it changes slowly relative to current.

The motor electrical block is:

\[

G_{\text{motor,electrical}}(s)

=

\frac{1}{R_A}

\frac{1}{1+s\frac{L_A}{R_A}}

\]

The PI controller contributes an integrator and a zero. If the PI zero and motor electrical pole are poorly placed, their phase contributions can combine to approach −180°.

If the open-loop gain magnitude is approximately one at a phase shift of approximately ±180°, the negative-feedback system effectively becomes positive feedback at that frequency. This can result in oscillation or instability.

Pole-zero cancellation design

The lecture proposes selecting the PI zero to coincide with the motor electrical pole:

\[

\frac{K_P}{K_I}

=

\frac{L_A}{R_A}

\]

This causes the PI-controller zero and the motor electrical pole to cancel in the simplified open-loop transfer function.

After cancellation, the remaining significant dynamic contribution in the simplified current-loop model is the integrator associated with the mechanical inertia:

\[

\frac{1}{J_{\text{total}}s}

\]

The lecturer states that this leaves a maximum phase shift of approximately −90°, preventing the system from reaching −180° phase shift under the simplified model.

This cancellation is a design simplification based on the model assumptions. It should not be treated as universally exact in a real system, where parameter uncertainty, delays, sampling, converter dynamics, unmodelled poles, and sensor dynamics may prevent perfect cancellation.

Gain, bandwidth, and disturbance rejection

For good tracking, the open-loop gain should be large at frequencies corresponding to the desired command dynamics. A large loop gain makes the closed-loop output approach the ordered value.

For high-frequency disturbances, the loop gain should be small so that those disturbances are attenuated rather than reproduced at the output. In this application, converter switching-frequency disturbances are specifically identified as disturbances that should be suppressed.

For a generic unity-feedback plant with open-loop gain \(G\), the closed-loop relationship is:

\[

\frac{Y}{R}

=

\frac{G}{1+G}

\]

where:

• \(R\) is the reference input.

• \(Y\) is the output.

When \(|G|\) is large:

\[

\frac{G}{1+G}\approx 1

\]

so the output approximately follows the reference.

When \(|G|\) is small, the output is attenuated relative to the reference.

The transition between these regions is associated with:

\[

|G|=1

\]

In a Bode magnitude plot, this corresponds to 0 dB. The lecture also identifies the −3 dB point as the closed-loop bandwidth or cutoff-frequency point.

Phase margin

At the frequency where the open-loop gain magnitude is one, the difference between the system phase and the −180° instability condition is the phase margin.

The lecture recommends a phase margin of at least approximately:

\[

45^\circ

\]

A substantial phase margin provides tolerance to noise and phase variations caused by real operating conditions. The lecturer describes 45° as generally satisfactory for practical applications, although not an absolute guarantee of good performance in every system.
